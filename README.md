# CalculadoraWinForms-INF512

Proyecto de la Unidad 2 de la asignatura INF512, que aplica el uso de Windows Forms en C# para crear una aplicación de escritorio con interfaz gráfica.

## Descripción

Esta aplicación es una calculadora básica desarrollada con Windows Forms (.NET). Permite ingresar dos números y realizar las cuatro operaciones aritméticas fundamentales a través de una interfaz visual con botones y campos de texto.

## Funcionalidades

- Suma, resta, multiplicación y división de dos números
- Validación de campos vacíos o con texto no numérico
- Manejo del error de división entre cero
- Interfaz gráfica simple e intuitiva

## Tecnología utilizada

- C#
- Windows Forms (.NET)

## Cómo ejecutar

1. Clonar o descargar el repositorio
2. Abrir el proyecto en Visual Studio
3. Ejecutar con F5
